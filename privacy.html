3.当社が運用する社内ツールによる Google ユーザーデータの取り扱い

当社は、自社で運営する YouTube チャンネルの運営・分析と経理のために、Google Cloud に登録した OAuth アプリ「keshitemimasu meter」を使う社内ツール（以下「本ツール」）を運用しています。本ツールは一般の方に提供するものではなく、利用するのは当社の役員・従業員に限られます。

3-1. 対象となるアカウント

本ツールが Google アカウントの認可を受けるのは、当社が管理する次のアカウントだけです。

  • 当社が運営する YouTube チャンネル（当社代表者の Google アカウント、および当社が管理するブランドアカウントに紐づくもの）
  • 当社が YouTube 等の収益の受け取りに使っている Google AdSense アカウント

このほか、分析の参考として、上記の認可を使って YouTube 上で一般に公開されている他のチャンネル・動画の公開情報を読み取ることがあります（3-3 に記載）。他のチャンネルの非公開の情報を取得したり、他のチャンネルに対して書き込みを行ったりすることはありません。

3-2. 利用する API・権限（スコープ）と目的

権限（スコープ） 利用する API 目的
https://www.googleapis.com/auth/yt-analytics.readonly YouTube Analytics API
YouTube Reporting API		 当社チャンネルの再生回数・視聴維持率などの集計データを取得するため。インプレッション数・クリック率のレポートを受け取る設定を登録し、そのレポートを取得するため
https://www.googleapis.com/auth/youtube.readonly YouTube Data API v3 当社チャンネルと動画の情報（タイトル、公開状態、高評価数など）と、分析の参考にする他のチャンネル・動画の公開情報を読み取るため
https://www.googleapis.com/auth/youtube.force-ssl YouTube Data API v3 当社チャンネルへの動画のアップロード（非公開または予約公開）、タイトル・説明文・サムネイル画像の設定、公開予約の変更、再生リストへの追加を行うため。この権限でコメントの読み取り・投稿・削除は行いません（3-3）
https://www.googleapis.com/auth/yt-analytics-monetary.readonly YouTube Analytics API 経理処理のため、当社チャンネルの日別の見積収益を取得するため
https://www.googleapis.com/auth/adsense.readonly AdSense Management API 経理処理のため、当社 AdSense アカウントの見積収益と支払い情報を取得するため

3-3. 取得・保存するデータ

  • チャンネルと動画の集計値：再生回数、総再生時間、平均視聴時間、平均視聴率、チャンネル登録者数とその増減、高評価数、コメント数、共有数、視聴者維持率、サムネイルのインプレッション数とクリック率、再生回数の多い動画の一覧
  • 視聴の傾向を表す統計：視聴者の年齢層・性別の割合、視聴に使われたデバイスの種類、流入元（関連動画、YouTube 検索で使われた語句など）、チャンネル登録の有無別の再生。いずれも YouTube が集計した統計で、個々の視聴者を特定する情報は含みません。
  • 当社の動画の情報：動画 ID、タイトル、説明文、タグ、カテゴリ、公開状態と公開予定日時、公開日、長さ、処理の状況、サムネイル画像
  • 当社の動画に寄せられたコメント：件数のみを取得します（YouTube Data API の commentCount。上記の集計値に含まれます）。コメントの本文、投稿者の表示名、コメント ID、返信は取得も保存もしません。本ツールからコメントを読み取る機能自体を 2026年9月17日に削除しました。コメントの内容は、当社の担当者が YouTube Studio の画面で読むにとどめます。
  • 他のチャンネル・動画の公開情報：分析の参考として、YouTube 上で一般に公開されている他のチャンネル・動画の情報（チャンネル名、動画の題名、再生回数、高評価数、コメント数、公開日、長さ）。コメントの本文や投稿者の情報は取得しません。
  • 収益の情報：日別の見積収益（広告収益、YouTube Premium 収益の内訳を含む）、AdSense の見積収益・ページビュー・インプレッション・クリック数、支払い情報
  • 認可情報：Google から発行されるアクセストークンとリフレッシュトークン

3-4. 本ツールが YouTube 上で行う操作

本ツールが YouTube に対して行う書き込みは、当社チャンネルへの動画のアップロード（非公開または予約公開）とタイトル・説明文等の設定、サムネイル画像の設定、公開予約の変更、再生リストへの追加、インプレッション数のレポートを受け取るための設定の登録に限られます。コメントの投稿や削除、動画の削除、当社以外のチャンネルに対する書き込みは行いません。

3-5. 保存場所と外部への送信

  • 取得したデータと認可情報は、当社が管理する社内のパソコン内に保存します。バックアップとして、同じパソコンの別の記憶装置、当社が管理する外付けの記憶装置、および当社側で暗号化したうえでクラウドストレージ（Cloudflare, Inc. の R2）にも複製を保存することがあります。
  • 取得したデータを外部に公開することはありません。データの一部が当社の外に送信されるのは、次の場合に限られます。
  • 社内連絡のための通知：動画の公開予約が完了したときに、動画のタイトル、公開予定日時、動画の URL、サムネイルの設定状況を当社の社内用 Discord チャンネルに通知します。また、月次の経理処理が終わったときに、その月の見積収益の合計額を当社の社内連絡用の Discord または LINE に通知します。
  • 生成 AI サービスによる作業の補助：当社の判断により、当社が承認した処理の委託先として、生成 AI サービス（Anthropic, PBC の Claude、OpenAI の Codex など）を使ってチャンネルの分析や制作の作業を行うことがあります。この場合、役員・従業員が行う作業と、当社の端末上で自動で実行する処理のいずれにおいても、3-3 のデータ（収益の情報と認可情報を除く）の内容が処理のために当該サービスへ送信されることがあります。送信するのは集計値・統計、当社の動画の情報、他のチャンネル・動画の公開情報です。コメントの本文・投稿者の表示名は、本ツールが取得も保存もしないため（3-3）、送信の対象にもなりません。
  • 経理・税務：収益の集計結果は、当社が経理・税務を委託している税理士に提出します。

3-6. 第三者への提供

当社は、Google ユーザーデータを販売したり、広告事業者やデータ仲介業者などの第三者に提供したりしません。3-5 に記載したサービス事業者・委託先での処理と、法令に基づく場合を除き、第三者に提供しません。

3-7. 保存期間と削除

保存期間は、データの種類ごとに次のとおりとします。バックアップに保存した複製も同じ扱いとします。

  • チャンネルと動画の集計値・視聴の傾向を表す統計（YouTube Analytics API・YouTube Reporting API から取得したデータと、再生回数などの統計）：チャンネルの運営と分析に必要な期間保存します。保存を続ける間は、少なくとも30日ごとに、当該アカウントの認可が引き続き有効であることを確認します。確認は、本ツールが毎日の取得の際にアクセストークンを更新できているかどうか（更新できた日時の記録）によって行います。
  • 当社の動画の情報、他のチャンネル・動画の公開情報、サムネイル画像の控え：取得から30日以内に削除するか、取り直して最新の内容に更新します。対象の一覧と、取得からの経過日数は、社内の点検用スクリプトで表示できるようにしており、担当者がこれを確認して削除または取り直しを行います（自動では削除しません）。なお、当社が自ら作成した動画・原稿・サムネイルの元データは、API から取得したデータではないため、この対象に含みません。
  • コメント：3-3 のとおり、本文・投稿者の表示名・コメント ID は取得も保存もしません。2026年9月17日より前に取得して保存していたものについても、取得から30日以内に削除します。
  • 収益の情報：法令で定められた帳簿書類の保存期間にあわせて保存します。
  • 認可情報：本ツールで使うのに必要な間だけ保存します。不要になった認可情報は、失効させたうえで削除します。

当社の動画にコメントを投稿された方などから、当社が保存しているデータの削除のご依頼を受けた場合は、速やかに、遅くとも7日以内に削除します。ご依頼は「10. お問い合わせ先」までご連絡ください。

当社が保存しているデータを削除しても、YouTube 上のデータ（コメント、動画など）は一切削除・変更されません。YouTube 上のデータの削除は、YouTube のアプリやウェブサイトから行ってください。

3-8. アクセスの取り消し

3-7 の削除のご依頼とは別に、Google のセキュリティ設定のページ（https://security.google.com/settings/security/permissions。現在は https://myaccount.google.com/permissions に転送されます）から、「keshitemimasu meter」のアクセスをいつでも取り消すことができます。取り消すと、本ツールは新たにデータを取得できなくなります。

アクセスが取り消された場合、またはトークンを更新できなくなった場合、当社は当該アカウントの認可に基づいて保存したデータを、速やかに、遅くとも7日以内に削除します。

4.Google API サービスのユーザーデータに関するポリシーへの準拠

「keshitemimasu meter」が Google API から受け取った情報の利用と、他のアプリへの移転は、限定使用（Limited Use）の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

keshitemimasu meter's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

当社は、Google ユーザーデータを広告の配信に利用したり、汎用的な AI・機械学習モデルの開発・改良・学習のために利用したりしません。

  • 本ツールは、利用する方のブラウザや端末に Cookie などの情報を保存したり、第三者に広告やコンテンツを配信させたりすることはありません。

  • 法令に基づく対応

7.個人情報の第三者提供

当社は、次の場合を除き、あらかじめご本人の同意を得ずに個人情報を第三者に提供しません。

  • 法令に基づく場合
  • 人の生命、身体または財産の保護のために必要がある場合で、ご本人の同意を得ることが困難なとき
  • 公衆衛生の向上または児童の健全な育成の推進のために特に必要がある場合で、ご本人の同意を得ることが困難なとき
  • 国の機関もしくは地方公共団体またはその委託を受けた者が法令の定める事務を遂行することに対して協力する必要がある場合で、ご本人の同意を得ることにより当該事務の遂行に支障を及ぼすおそれがあるとき

なお、利用目的の達成に必要な範囲で個人情報の取り扱いを外部に委託する場合（3-5 に記載したサービス事業者の利用や、税理士への経理業務の委託など）は、委託先を適切に監督します。

8.安全管理措置

当社は、個人情報の漏えい、滅失または毀損を防ぐため、次の措置を講じます。

  • 個人情報を取り扱う者を限定し、取り扱いのルールを定めます。
  • 個人情報を保存する端末と記憶装置は当社が管理し、関係者以外が扱えないようにします。
  • API の認可情報などの鍵はプログラムの中に書かず、決められた場所で管理します。クラウドストレージへのバックアップは暗号化して保存します。
  • 外的環境の把握：当社は、外国の事業者が提供する次のサービスを利用しており、利用にあたっては各国の個人情報の保護に関する制度を把握したうえで、必要な措置を講じます。
  • 米国の事業者：GitHub, Inc.（本ウェブサイトの公開）、Google LLC（Web フォント、Google API）、Cloudflare, Inc.（バックアップの保存）、Discord Inc.（社内連絡）、Anthropic, PBC と OpenAI（生成 AI サービス）
  • 米国には、日本の個人情報保護法に相当する連邦レベルの包括的な個人情報保護法はなく、州法や分野ごとの法律によって個人情報が保護されています。
  • このほか、国内の事業者として LINEヤフー株式会社（社内連絡）のサービスを利用しています。
